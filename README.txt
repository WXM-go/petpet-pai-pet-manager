派派桌宠管理器

这是一个 Windows 10/11 64 位便携版桌宠管理器。

使用方法：
1. 解压整个 PetPet-Windows-x64 文件夹。
2. 双击“派派桌宠管理器.exe”。
3. 在管理器中点击“导入桌宠”，选择朋友发来的 ZIP 或桌宠文件夹。
4. 点击桌宠卡片即可切换，点击“运行桌宠”即可显示在桌面上。

功能：
- 管理多个桌宠并随时切换。
- 桌宠窗口透明、置顶，可用鼠标左键拖动。
- 右键桌宠可以播放动作、选择方向、调整大小和打开预览。
- 单击桌宠可以打开摸摸、喂零食、一起玩、休息互动。
- 默认桌宠软团团支持快乐、饱腹、精力三项轻养成状态，长时间不互动会打瞌睡。
- 支持像素、插画、二次元、3D、手绘等风格，并按桌宠包声明选择清晰或平滑渲染。
- 鼠标跟随只读取屏幕坐标，用于判断桌宠朝向。
- 键盘动作只检测是否发生键盘活动，不读取、不保存具体输入内容。
- 桌宠包只复制 pet.json、精灵图、预览图和说明文件，不执行脚本。

存储：
- 优先保存在程序目录下的 pets 文件夹。
- 如果程序目录不可写，则自动使用 Windows 用户数据目录。

注意：
- 请把程序文件夹整体解压后运行，不要只复制 EXE。
- 第一次运行可能出现 Windows SmartScreen 提示，这是未进行代码签名的便携程序提示。
- 本软件不需要安装 Codex、Node.js 或 Python。
