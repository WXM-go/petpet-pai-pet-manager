# 派派桌宠管理器 v1.1.0 稳定优化版实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Each task must先写验收条件，再修改代码，并在岗位对话末尾完成交接。

**Goal:** 在现有可运行的 v1.0.0 基础上，完成桌宠包安全与兼容、运行时一致性、Windows 稳定性、管理器体验和可重复发布流程，形成可封版的 v1.1.0。

**Architecture:** 保留现有 Electron 主进程、预加载、管理器页面、桌面渲染器和轻养成模型；先稳定 `pet.json` v2 与导入边界，再让 Electron、运行时和管理器前端按稳定接口联调，最后由 QA 和发布岗位封版。软团团作为默认桌宠继续保留，像素风和非像素风仍使用同一套桌宠包接口。

**Tech Stack:** Electron 44、Node.js、HTML/CSS/JavaScript、Canvas 精灵图渲染、`extract-zip`、Node 内置测试、Windows 10/11 x64 便携打包。

**Spec:** `findings.md`、`progress.md`、`task_plan.md`、`团队协作分工.md`、现有源码与用户上传的团队分工截图。

## Global Constraints

- 本周期基于当前能运行的版本优化，不按从零开发估算。
- 继续使用自然简体中文，不增加首版语言切换。
- 继续支持像素、插画、二次元、3D、手绘等桌宠风格，管理器不得假设只能使用像素风。
- 六档尺寸继续保留：50%、65%、80%、100%、125%、150%；50% 下必须仍可拖动、单击、右键和底部锚定。
- 首版桌宠包不执行任意脚本；`full-care` 只保留兼容提示，不在本周期实现沙箱养成系统。
- 软团团继续是首次启动的默认桌宠；互动动画不能与底层动作叠加产生重影，睡眠状态不能被自动动作打断。
- 本地首个 Git 提交属于基线保护，不连接、不创建、不推送 GitHub；涉及 GitHub 时另行向用户确认。
- 封版后产生的新想法统一进入待办，不自动改变封版日期或扩大本周期范围。

## 1. 目标与期限

### 周期建议

- **建议周期：2026-09-14 至 2026-10-16，共 5 周。**
- **目标版本：v1.1.0「稳定优化版」**，不是重新开发版。
- **候选版本日：2026-10-12。**
- **正式封版日期：2026-10-16 18:00（中国标准时间）。**
- **封版后：**只允许处理 S0/S1 阻断问题；新增想法进入下一版本待办。

这个估算基于岗位对话可以并行推进、总协调在四个阶段门进行确认，并假设每个阶段门能在 1 个工作日内得到用户决定；没有套用个人每周投入次数或单次时长。

**用户已确认：**采用 A 节奏；接受建立本地首个 Git 基线提交；项目最终必须连接并上传 GitHub。GitHub 的具体账号、仓库名和首次推送仍在实际操作前单独确认。

### 当前基线判断

- 当前 `package.json` 为 `1.0.0`，应用可以运行，已有桌宠、管理器、测试和 Windows 便携版产物。
- 当前测试记录为 46/46 通过，但现有测试主要是纯函数、资源报告和静态 UI 契约，真实 Electron 主流程覆盖不足。
- 当前仓库尚无首个 Git 提交；源码、资源和测试均处于未提交工作区，因此必须先保存可回滚基线。
- 已确认的主要风险来自 `findings.md`：桌宠包校验不完整、导入失败回滚不足、能力声明与运行时不完全贯通、Windows 集成能力不足、发布目录可能残留运行态数据、管理器状态更新效率和错误反馈不足。
- 用户上传的团队分工图可读取，岗位与当前 `团队协作分工.md` 一致；没有看到具体成员姓名，因此本计划只按岗位对话分配，不臆造个人成员。

## 5. 统一验收标准

### 功能与兼容

- 现有可运行能力不倒退：透明置顶、拖动、鼠标跟随、键盘联动、动作预览、ZIP/文件夹导入、切换、暂停和退出均可复现验证。
- 50%、65%、80%、100%、125%、150% 六档可选；50% 下仍可操作，桌宠底部位置稳定。
- 像素风默认清晰渲染；声明平滑渲染的插画、3D、手绘等桌宠不被强制像素化。
- 无专属互动动画的旧桌宠可以安全回退到标准动作；声明未来能力的桌宠显示中文兼容提示，不崩溃、不静默失效。

### 资源质量

- 软团团互动动作只有一个可见播放层，不出现底层残影、重影和紫色边缘。
- 睡眠状态只播放睡眠/待机允许的内容，不被自动演示、键盘动作或其他动作打断。
- 图集尺寸、动作行、方向、透明边缘、互动资源键名和资源哈希均有机器检查或可重复视觉检查。

### 测试与发布

- `npm test` 全部通过；`src/*.js` 语法检查通过。
- 至少完成真实 Electron 启动、IPC、导入、窗口、桌宠交互和退出冒烟。
- 发布目录经过清理和白名单检查，不带用户运行态数据。
- QA 报告包含测试环境、步骤、结果、证据、已知问题和阻断结论。
- S0 为 0；S1 必须关闭或有总协调批准的延期记录；任何延期都进入下一版本待办。
