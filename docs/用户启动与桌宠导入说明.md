# 派派桌宠管理器

## 启动

1. 解压完整的 `派派桌宠管理器-win32-x64` 文件夹。
2. 双击其中的 `派派桌宠管理器.exe`。
3. 首次启动时，软团团会作为默认桌宠出现，管理器窗口也会打开。

程序是 Windows 10/11 x64 便携版，不需要安装 Codex、Node.js 或 Python。Windows SmartScreen 可能提示程序尚未签名，这是便携程序首次运行时的系统提示。

请保留整个文件夹，不要只复制 EXE。程序需要同目录下的 Electron 运行文件和资源。

## 导入桌宠

### 导入 ZIP

1. 在管理器中点击“导入桌宠”。
2. 选择朋友发来的桌宠 ZIP 文件。
3. 导入完成后，桌宠会出现在“桌宠库”中。
4. 点击桌宠卡片，再点击“运行桌宠”。

### 导入文件夹

1. 点击“更多”。
2. 选择从文件夹导入的入口。
3. 选择包含 `pet.json` 和 `spritesheet.webp` 的桌宠文件夹。
4. 回到“桌宠库”选择并运行桌宠。

## 桌宠包要求

桌宠包至少需要 `pet.json` 和 `spritesheet.webp`。预览图、互动动画和说明文件按桌宠包声明使用。派派只读取支持的图片与配置，不运行桌宠包中的脚本。

## 常用操作

- 左键按住桌宠：移动位置。
- 单击桌宠：打开“摸摸、喂零食、一起玩、休息”互动。
- 右键桌宠：打开动作、方向、大小和预览菜单。
- “隐藏桌宠”：暂时隐藏桌宠，之后可从管理器重新运行。
- 支持 50%、65%、80%、100%、125%、150% 六档大小。

## 存储与卸载

导入的桌宠优先保存在程序目录的 `pets` 文件夹；程序目录不可写时，会改用 Windows 用户数据目录。卸载时先退出派派，再删除解压出来的程序文件夹。
