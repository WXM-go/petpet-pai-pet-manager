# 更新日志

## 1.0.0 · 2026-09-16

当前工作区的 Windows 10/11 x64 便携版更新记录：

- 修复 Windows 环境下 sandboxed renderer 启动失败的问题，三个 BrowserWindow 明确使用 `sandbox: false`。
- 保留 `contextIsolation: true`、`nodeIntegration: false` 和受限 preload IPC。
- 增加 renderer、preload、页面加载和子进程诊断日志。
- 完善桌宠运行时能力报告、动作映射、互动回退和睡眠状态处理。
- 修复鼠标跟随关闭后一次性动作结束方向残留的问题。
- 保留中文优先界面、六档桌宠大小、软团团默认桌宠和多画风渲染。
- 重新生成 Windows x64 便携版，并将发布包与 QA 运行态数据分离。

### 已知限制

- 首次运行可能出现 Windows SmartScreen 提示。
- `full-care` 能力保留兼容提示，完整养成系统不在本版本范围内。
